\subsection{Architectural pattern}

Dự án sử dụng mô hình \textbf{MVCS} (Model--View--Controller--Service) cho backend API, kết hợp với kiến trúc frontend theo feature/module ở phía React. Kiến trúc chuẩn của \textbf{MVCS} được thể hiện trong \ref{fig:mvcs-pattern}:

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.8\textwidth]{Images/MVCS.png}
    \caption{MVCS pattern}
    \label{fig:mvcs-pattern}
\end{figure}

\textbf{MVCS} giúp tách rõ trách nhiệm giữa giao diện, API endpoint, business logic và tầng truy cập dữ liệu. Cách tổ chức này phù hợp với hệ thống Social Commerce vì các miền nghiệp vụ như xác thực, bài viết, sản phẩm, đơn hàng, tin nhắn, thông báo, AI và quản trị đều có logic riêng nhưng vẫn cần chia sẻ dữ liệu qua cùng database.

\begin{itemize}
    \item \textbf{View Layer}: Được xây dựng bằng \textbf{React.js}, \textbf{TypeScript} và \textbf{Vite}. Dự án có hai frontend riêng: ứng dụng người dùng trong thư mục \texttt{frontend} và ứng dụng quản trị trong thư mục \texttt{admin/frontend}.
    \item \textbf{Controller Layer}: Được xây dựng bằng \textbf{Express.js}. Controller nhận HTTP request, gọi service phù hợp và trả response chuẩn hóa cho frontend.
    \item \textbf{Service Layer}: Chứa business logic như xác thực, seller verification, feed, product CRUD, cart/order, refund giả lập, messaging, notification, AI content generation, AI shopping assistant, report moderation và cache invalidation cho các dữ liệu đọc nhiều.
    \item \textbf{Model/Data Access Layer}: Sử dụng \textbf{Prisma ORM} để truy cập \textbf{PostgreSQL}. Schema được định nghĩa tại \texttt{database/prisma/schema.prisma} và Prisma Client được generate cho backend.
\end{itemize}

\subsection{Architecture diagram}

Các frontend giao tiếp với backend thông qua HTTP request; tính năng real-time như chat và notification sử dụng Socket.IO trên core API.

\paragraph{Frontend Structure} Ứng dụng người dùng được tổ chức theo các vùng chức năng chính:

\begin{itemize}
    \item \textbf{Routing}: Quản lý navigation cho auth, feed, marketplace, product detail, cart, checkout, orders, groups, messages, notifications, saved items, AI creative lab và seller dashboard.
    \item \textbf{Features}: Chia theo nghiệp vụ như authentication, feed, profile, product, cart, order, group, messaging, notification, seller, report, AI creative lab và AI shopping assistant.
    \item \textbf{Shared Layer}: Chứa API client, UI components, auth guards, utilities và các thành phần dùng chung.
    \item \textbf{API Client}: Sử dụng fetch wrapper nội bộ để gọi REST API và gắn token khi route yêu cầu xác thực.
    \item \textbf{Socket.IO Client}: Kết nối real-time cho notification, message dock, typing indicator và trạng thái online.
\end{itemize}

\paragraph{Admin Frontend Structure} Ứng dụng admin là frontend riêng, phục vụ các trang quản trị:

\begin{itemize}
    \item \textbf{Dashboard}: Thống kê tổng quan user, seller, buyer, product, post, order, revenue và growth.
    \item \textbf{Users}: Tìm kiếm, lọc, khóa/mở khóa và thay đổi role phù hợp.
    \item \textbf{Content}: Quản lý bài viết và sản phẩm.
    \item \textbf{Reports}: Xem chi tiết và xử lý báo cáo vi phạm.
    \item \textbf{Categories}: Quản lý danh mục sản phẩm.
    \item \textbf{Sellers}: Duyệt hồ sơ seller và yêu cầu thay đổi dữ liệu nhạy cảm.
\end{itemize}

\paragraph{Core Backend Structure} Core backend nằm trong thư mục \texttt{backend} và được xây dựng bằng \textbf{Node.js} + \textbf{Express.js}. Cấu trúc bao gồm:

\begin{itemize}
    \item \textbf{API Routes}: Mount các module tại \texttt{/api/auth}, \texttt{/api/users}, \texttt{/api/posts}, \texttt{/api/products}, \texttt{/api/cart}, \texttt{/api/orders}, \texttt{/api/reviews}, \texttt{/api/saved-items}, \texttt{/api/search}, \texttt{/api/notifications}, \texttt{/api/ai}, \texttt{/api/ai-assistant}, \texttt{/api/scheduled-posts}, \texttt{/api/seller}, \texttt{/api/messages}, \texttt{/api/groups} và \texttt{/api/reports}.
    \item \textbf{Middleware}: Xác thực JWT, kiểm tra role, validate dữ liệu, rate limiting, CORS, helmet và error handling.
    \item \textbf{Controllers}: Nhận request và điều phối sang service tương ứng.
    \item \textbf{Services}: Chứa logic nghiệp vụ của từng module.
    \item \textbf{Cache Layer}: Sử dụng Redis thông qua helper \texttt{backend/src/lib/cache.js} để cache danh sách/chi tiết sản phẩm, danh sách/chi tiết bài viết, bình luận bài viết và kết quả tìm kiếm. Khi tạo/sửa/xóa bài viết hoặc sản phẩm, controller xóa các cache key liên quan.
    \item \textbf{Socket.IO}: Khởi tạo cùng HTTP server để hỗ trợ realtime message và notification.
    \item \textbf{Scheduler}: Chạy node-cron để publish scheduled posts và purge sản phẩm đã soft-delete khi đến hạn.
\end{itemize}

\paragraph{Admin Backend Structure} Admin backend nằm trong thư mục \texttt{admin/backend}. API này tách biệt với core API để phục vụ ứng dụng quản trị:

\begin{itemize}
    \item \textbf{Auth}: Đăng nhập admin, cấp admin JWT và kiểm tra phiên.
    \item \textbf{Admin}: Quản lý users, posts, products, categories và dashboard.
    \item \textbf{Reports}: Xem, lọc và resolve báo cáo vi phạm.
    \item \textbf{Seller Admin}: Duyệt seller applications và sensitive change requests.
\end{itemize}

\paragraph{Database \& Cache} Hệ thống sử dụng \textbf{PostgreSQL} làm database chính. Backend truy cập database thông qua \textbf{Prisma ORM}. Schema tập trung trong \texttt{database/prisma/schema.prisma}, bao gồm các nhóm bảng cho user/auth, seller verification, product/category, cart/order, post/social, group, messaging, notification, review, AI history, analytics và report. Ngoài ra, core API có thể kết nối \textbf{Redis} qua biến môi trường \texttt{REDIS\_URL} để cache dữ liệu đọc nhiều; nếu Redis không được cấu hình, helper cache tự bỏ qua và hệ thống vẫn đọc trực tiếp từ PostgreSQL.

\paragraph{Code \& Version Control} Source code được quản lý bằng \textbf{GitHub}. Cấu hình triển khai production được mô tả trong \texttt{render.yaml} với bốn service trên Render: \texttt{soco-api}, \texttt{soco-admin-api}, \texttt{soco-main} và \texttt{soco-admin}.

\paragraph{Testing \& Development Tools} Hệ thống sử dụng các công cụ hỗ trợ:

\begin{itemize}
    \item \textbf{API Testing}: Postman hoặc Swagger UI cho kiểm thử endpoint.
    \item \textbf{Frontend Testing}: Vitest và Testing Library ở một số feature/hook.
    \item \textbf{Database Tooling}: Prisma Client và Prisma schema để đồng bộ model với PostgreSQL.
\end{itemize}

\paragraph{External Services} Hệ thống tích hợp với các dịch vụ bên ngoài:

\begin{itemize}
    \item \textbf{AI Text API}: Google Gemini là provider chính; OpenRouter/Groq có thể được cấu hình làm provider dự phòng cho text/vision và AI shopping assistant.
    \item \textbf{AI Image API}: Hugging Face hoặc Replicate được dùng để tạo ảnh nếu token được cấu hình. Tạo video chưa nằm trong kiến trúc triển khai hiện tại.
    \item \textbf{File Storage}: Cloudinary được dùng cho upload ảnh sản phẩm, bài viết, avatar, shop assets và giấy tờ seller.
    \item \textbf{Email Service}: SMTP qua Nodemailer được dùng cho xác thực email, OTP 2FA và reset password.
\end{itemize}
